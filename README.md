# Nabhni

A Flutter app about power outages in Egypt. It was built by a team during an Innovegypt entrepreneurship training, from research and user interviews.

## My role
I led the Flutter development. The UI/UX design was by Ahmed Alaa Tawfik.

## Stack
- Flutter and Dart
- MVVM with Bloc (flutter_bloc), get_it for dependency injection
- Firebase Authentication (email and Google sign-in) and Notifications
- dio and retrofit for API calls

## Status
Some features are incomplete. The idea needed a backend, and the app used free public APIs instead.
